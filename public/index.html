Catatan koneksi

Kredensial WhatsApp berada di volume AUTH_DIR. Jadwal dan aturan auto-reply berada di DATA_DIR dan perlu volume persisten terpisah pada Railway.

Gunakan API key melalui backend aplikasi Anda; jangan menanamnya di frontend publik.
